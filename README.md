# Мой ритм сегодня

Одностраничное веб-приложение: помогает ежедневно сопоставить предполагаемую фазу цикла
с фактическим состоянием тела и получить короткие рекомендации на сегодня.

Это не трекер месячных. Логика другая:

**цикл + состояние тела → режим дня → рекомендации → вечерняя обратная связь**

Главный принцип: если предполагаемая фаза и фактическое состояние противоречат друг другу,
приоритет всегда у состояния.

## Как запустить

Двойной клик по `index.html`. Если хочется, чтобы наблюдения точно сохранялись,
лучше поднять локальный сервер в этой папке:

```bash
python -m http.server 8123
```

и открыть `http://localhost:8123`.

## Что внутри

| Файл | Что это |

| `index.html` | всё приложение: интерфейс, алгоритм, тексты рекомендаций |

## Статистика

Личные данные остаются на устройстве. Наружу уходит только название события, дата
и источник перехода — подробности в `ANALYTICS.md`. Пока приёмник не подключён,
события копятся в браузере, и воронку можно посмотреть на `admin.html`.

## Как устроен алгоритм

**Фаза цикла** считается по дате последней менструации, длине цикла и длительности
менструации. Овуляторное окно — примерно за 14 дней до следующей менструации, плюс-минус
пара дней; при нерегулярном цикле окно шире. Всё это предположение, а не факт:
приложение не определяет овуляцию и ничего не диагностирует.

**Режим тела** определяется по пяти вопросам о самочувствии. У каждого варианта ответа
есть скрытые веса по четырём режимам — *Создавать*, *Проявлять*, *Собирать*, *Интегрировать*.
Ответы про пробуждение и про желания тела весят больше остальных: это прямые телесные
сигналы. Никаких баллов и шкал пользовательница не видит. Если два режима практически
равны, показывается переходный: например «Проявлять → Собирать».

**Совпадение** фазы и состояния бывает трёх видов: совпало, отчасти совпало, разошлось.
Рекомендации в любом случае берутся из фактического режима — фаза остаётся фоном.

## Данные

Собираются только: анонимный идентификатор, дата, день цикла, предполагаемая фаза, ответы,
режим тела, отметка совпадения, вечерние ответы и факт визита. Имя, почта, телефон и дата
рождения не спрашиваются нигде.

Пока в `index.html` в блоке `CONFIG` стоит `BACKEND: "local"`, всё хранится в браузере
устройства. Переключение на Supabase описано в `SUPABASE.md` и не требует правок
в остальном коде.

## Проверка алгоритма

В консоли браузера доступен объект `RITM` — можно проверить расчёты на любых данных:

```js
RITM.computeCycle({cycle_length: 28, period_length: 5, is_regular: true,
                   last_period_start: "2026-08-11"}, "2026-08-23")
// → { day: 13, phase: "ovulatory", ovuStart: 13, ovuEnd: 17, … }

RITM.computeMode({q1: "d", q2: "d", q3: "d", q4: "d", q5: "d"})
// → { mode: "integrate", mode_secondary: null, is_transition: false }
```
