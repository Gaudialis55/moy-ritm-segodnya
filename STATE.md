## Что умеет приложение

**Экран 1 — приветствие.** Название, смысл проекта в двух абзацах, кнопка «Узнать свой ритм»,
раскрывающийся блок «Что это и как работает» (пять шагов, четыре фазы, принцип, об авторе).
Вернувшейся женщине преамбула и блок не показываются.

**Экран 2 — данные цикла.** Дата последней менструации тремя списками (день, месяц, год) —
свой выбор вместо нативного `<input type="date">`, потому что тот рисуется на языке браузера.
Длина цикла 21–40, менструация 2–10, регулярность.

**Экраны 3–7 — пять вопросов** о самочувствии, по одному на экран.

**Экран результата.** День цикла и предполагаемая фаза, режим тела, совпадение с фазой,
пять рекомендаций, вопрос дня. Кнопки «Попробую сегодня» и «Отметиться вечером».

**Экран «Попробую сегодня».** Вопрос попадания результата: очень похоже / частично / не похоже.

**Вечерний check-in.** Сначала оценка эффекта дня (легче / без разницы / не подошло),
затем три текстовых вопроса. После 18:00 предлагается первым экраном при возврате.

**Мой ритм** — история наблюдений.

**Мой ритм вперёд** — календарь фаз на три месяца, клик по дате открывает карточку
с режимом, фазой и возможным фокусом.

**Приватность** — что хранится, что отправляется, кнопка «Удалить мои данные с устройства».

### Алгоритм

День цикла: `((сегодня − дата начала) mod длина) + 1`.

Фазы: менструальная `day ≤ M`; овуляторное окно `[L−15, L−11]`, обрезанное снизу `M+1`
и сверху `L−1` (при нерегулярном цикле шире на день в обе стороны; при коротком цикле
с длинной менструацией окна может не быть вовсе); фолликулярная — между ними;
лютеиновая — после, последние три дня перед менструацией отдельная `luteal_late`.

Режим: у каждого варианта ответа скрытые веса по четырём режимам, вопросы о пробуждении
и желаниях тела весят в 1.5 раза больше. Порог переходного режима `TRANSITION_GAP = 0.5` —
переходный выпадает примерно в четверти раскладов.

Совпадение фазы и состояния: совпало / отчасти / разошлось. **Рекомендации всегда берутся
из фактического режима**, фаза остаётся фоном.

### Хранение

Всё личное — в `localStorage` браузера: `ritm.profile`, `ritm.entries`, `ritm.visits`,
`ritm.anon_id`. Слой `Store` с реализациями `LocalStore` (активна) и `SupabaseStore`
(заготовка). Переключение — `CONFIG.BACKEND`.

## Статистика

**Что уходит на сервер:** только `{ event, event_date, source }`. Ни идентификатора,
ни дня цикла, ни ответов, ни текстов.

**Пятнадцать событий:** `OPEN`, `START`, `RESULT`, `TRY_TODAY`, `FIT_YES`, `FIT_PARTLY`,
`FIT_NO`, `EVENING_START`, `EVENING_DONE`, `HELPED`, `NO_CHANGE`, `DID_NOT_FIT`,
`FORECAST`, `RETURN_D1`, `RETURN_D7`.

Возвраты считаются по локальной дате первого визита (`ritm.an.first`) и разовым флагам
(`ritm.an.flags`), без серверного идентификатора. Очередь `ritm.an.queue` переживает
отсутствие сети.

### База

Таблица `public.events` — события. Таблица `public.admins` — список тех, кто может читать статистику.

Политики: вставка только роли `anon` (публичный ключ), чтение только тем, кто есть в `admins`.
Удаление и изменение не разрешены никому. Ограничения отсекают посторонние коды событий
и мусор в источнике.

Ключ в коде сайта — `sb_publishable_SQ512jPGgd9-i6aGEy7T0w_sJkDXOAU`, publishable,
публичный по замыслу, даёт только вставку.

### Доступ к панели

Админы: `gaudialis55@gmail.com`, `4anna_che@mail.ru`.

Добавить нового: Authentication → Users → Add user (почта, пароль, «Auto confirm»),
затем в SQL Editor:

```sql
insert into public.admins (user_id, email)
select id, email from auth.users where email = 'новый@почта'
on conflict (user_id) do nothing;
```

Защита: самостоятельная регистрация отключена, пароль от 12 символов со всеми группами,
смена пароля требует текущего, вход — не чаще 10 попыток за 5 минут с адреса.

## Что важно помнить

**GitHub Pages кэширует страницы.** После публикации браузер может показывать старую версию.
Лечится жёстким обновлением или параметром в адресе `?v=2`. При проверках после каждой
правки нужен новый номер.

**Сборка Pages занимает до нескольких минут.** Статус:
`gh api repos/Gaudialis55/moy-ritm-segodnya/pages/builds/latest --jq '.status'`.

**iPhone занижает удержание.** Safari стирает хранилище сайта после недели без визитов:
вернувшаяся на восьмой день посчитается новой, `RETURN_D7` не уйдёт. Отсюда просьба
со сцены добавлять приложение на домашний экран.

**Приложение и панель на одном домене** — общий `localStorage`. Полная очистка хранилища
разлогинивает панель. Кнопка «Удалить мои данные» в приложении удаляет только ключи `ritm.*`,
поэтому пользователям это не мешает.

**Малые числа обманывают.** При сорока участницах разница 15% и 25% удержания
статистически неразличима; смотреть на порядок величины и кратную разницу между аудиториями.

**Публичный ключ позволяет накрутку.** Кто угодно может отправить события, зная ключ
из кода страницы. Ограничения в таблице отсекают мусор, но не подделку. Для пилота приемлемо.
