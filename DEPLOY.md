# Публикация приложения

## Приложение уже опубликовано

**Адрес:** https://gaudialis55.github.io/moy-ritm-segodnya/
**Репозиторий:** https://github.com/Gaudialis55/moy-ritm-segodnya (публичный)

Как выкатить правки: изменить `index.html` и выполнить в папке проекта

```bash
git add index.html && git commit -m "правка" && git push
```

Через минуту-две обновление появится на сайте. Если браузер показывает старую
версию — жёсткое обновление, Ctrl+Shift+R.

Ниже — общие инструкции, если понадобится перенести приложение в другое место.


Приложение — один статический файл `index.html` без сборки и зависимостей. Подойдёт
любой хостинг статики. Ниже два самых быстрых способа и один локальный.

---

## Способ 1. Netlify Drop — минута, без аккаунта и без Git

1. Открыть [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащить в окно браузера **папку** с `index.html`.
3. Получить адрес вида `https://случайное-имя.netlify.app` — он уже работает.
4. Чтобы адрес не потерялся, завести бесплатный аккаунт и в **Site settings → Change site name**
   задать понятное имя, например `moy-ritm-segodnya`.

Обновление: перетащить папку заново в тот же сайт (**Deploys → Drag and drop**).

---

## Способ 2. GitHub Pages — если хочется истории версий

1. Создать репозиторий на GitHub (можно приватный — Pages работает и с ним на бесплатном тарифе
   для публичных, для приватных нужен платный).
2. Загрузить `index.html` в корень ветки `main` (кнопка **Add file → Upload files**).
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`, **Save**.
4. Через одну–две минуты адрес будет `https://имя-пользователя.github.io/имя-репозитория/`.

Обновление: заменить файл в репозитории, публикация подхватится сама.

---

## Способ 3. Локально, чтобы просто посмотреть

Двойной клик по `index.html` откроет страницу, но в некоторых браузерах на `file://`
не работает `localStorage` — тогда данные не сохранятся. Надёжнее поднять локальный сервер
в папке проекта:

```bash
python -m http.server 8123
```

и открыть `http://localhost:8123`.

## Добавить на домашний экран телефона

Мета-теги для этого в `index.html` уже стоят — приложение открывается на весь экран,
без адресной строки, с тёплым белым фоном.

- **iPhone (Safari):** открыть сайт → «Поделиться» → «На экран "Домой"».
- **Android (Chrome):** открыть сайт → меню «⋮» → «Добавить на главный экран».

Полноценным PWA (офлайн-режим, установка из браузера) это пока не является: нет
`manifest.json` и service worker. Для MVP они не нужны — приложение и так работает
без интернета после первой загрузки, кроме подгрузки шрифта, у которого есть запасной вариант.

## Что важно помнить про данные

- Пока `CONFIG.BACKEND` равен `"local"`, все наблюдения лежат **только в браузере**
  конкретного устройства. Очистка данных сайта или другой телефон — история начнётся заново.
- После подключения Supabase (см. `SUPABASE.md`) данные уходят в облако и переживают
  очистку браузера, но привязка остаётся к анонимной сессии этого устройства.
- Публичный ключ `anon public` в коде страницы — норма. Ключ `service_role` в клиентский
  код класть нельзя никогда.

## Проверка после публикации

1. Открыть адрес с телефона.
2. Пройти путь целиком: данные цикла → пять вопросов → результат.
3. Перезагрузить страницу — приложение должно поздороваться как со знакомой и не спрашивать
   данные цикла заново.
4. Зайти после 18:00 — первым экраном должен предложиться вечерний check-in.
